# Text Analyzer

یک برنامه‌ی ساده‌ی پایتون که یک فایل متنی را تحلیل می‌کند.

## امکانات
- شمارش کل کلمه‌ها و جمله‌ها
- پیدا کردن طولانی‌ترین کلمه
- نمایش ۱۰ کلمه‌ی پرتکرار
- ذخیره‌ی گزارش در report.txt

## نحوه‌ی اجرا
1. متن خود را در sample.txt بگذارید
2. اجرا کنید:

    python main.py

3. نتیجه در report.txt ذخیره می‌شود
